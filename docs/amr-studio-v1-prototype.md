# AMR Studio V1 prototype review

## Scope and isolation

The prototype adds a standalone `services/studio` Cloudflare Worker. It deliberately does not change the existing GitHub Pages Cinema routes, media, engagement Worker, production D1 database, release workflow, or sitemap.

The test service uses its own D1 database and private R2 buckets. Studio pages, media reads, draft previews, and test-published previews all require a valid server-signed session. No route publishes a film to the public AMR site.

## Workflow

1. Sign in with the Studio passphrase.
2. Enter title and description and save a draft.
3. Upload one MP4 (maximum 50 MB) and one JPEG, PNG, or WebP poster (maximum 5 MB).
4. Review the film in the embedded player or protected viewer route.
5. Use **Test publish** or **Unpublish**. This changes only the isolated D1 status.

## Security controls

- The admin password and session signing key are Worker secrets, never browser configuration.
- Sessions are signed, eight-hour, `HttpOnly`, `Secure`, and `SameSite=Strict` cookies.
- Every mutation requires an exact same-origin request.
- Login attempts are rate-limited per keyed IP hash.
- Uploads require a bounded `Content-Length`, an allowed MIME type, and matching MP4/image magic bytes.
- Object keys are generated by the server and media stays in private R2 storage.
- HTML uses a restrictive Content Security Policy, frame denial, no-referrer policy, MIME sniffing protection, and `noindex` headers.
- Generic error responses avoid exposing database or storage details.
- Cloudflare Access is recommended as a second layer before sharing a remote preview.

This is intentionally a small owner-review prototype, not a general multi-user CMS. It has one administrative role and no asset deletion, audit dashboard, transcoding, analytics, notifications, member administration, or production release integration.

## Operating cost estimate

Pricing checked November 9, 2026:

- **Expected prototype cost: $0/month** at owner-review traffic and under roughly 10 GB of stored test media.
- Workers Free includes 100,000 requests per day. Workers Paid starts at $5/month if the account needs paid limits.
- D1 Free includes 5 million rows read/day, 100,000 rows written/day, and 5 GB total storage.
- R2 Standard includes 10 GB-month storage, 1 million Class A operations/month, 10 million Class B operations/month, and free egress. Above the included storage, Standard storage is $0.015/GB-month; Class A is $4.50/million and Class B is $0.36/million.

At the prototype's 50 MB per-film cap, 20 maximum-size test films plus posters are about 1 GB, comfortably inside the R2 free allowance. The largest cost risk is leaving obsolete test videos in storage; periodic manual cleanup is appropriate for V1.

## Owner review checklist

- Confirm the 50 MB MP4 limit is acceptable for Studio test clips.
- Create only test D1/R2 resources and confirm their names before remote deployment.
- Store two long random secrets and add Cloudflare Access.
- Verify a remote upload, preview, test publish, unpublish, and session expiry.
- Keep the Worker on a test-only hostname; do not map the AMR production domain.
- Do not merge until the owner explicitly approves the prototype.
